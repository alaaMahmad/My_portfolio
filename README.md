# Portfolio Website | Alaa Ahmad

A responsive, multi-language personal portfolio website built with clean, modern front-end technologies. This platform showcases my technical skills, software engineering background, contact details, and featured web development projects with live demo and GitHub source links.

---

## Key Features

- **Bilingual Support (EN / AR):** Dynamic internationalization (`i18n`) engine supporting English (LTR) and Arabic (RTL) layouts with seamless local storage persistence.
- **Dark / Light Theme Toggle:** Customizable appearance with CSS variables and automatic state caching via `localStorage`.
- **Featured Projects Showcase:** Highlighted interactive applications with descriptions, technical tags, GitHub repositories, and live demo links.
- **Responsive Layout:** Modern CSS Grid & Flexbox architecture tailored for desktop, tablet, and mobile displays.
- **Downloadable Resume:** Direct access to download my latest PDF resume directly from the navigation bar.

---

## Technical Stack

- **Front-End:** HTML5, CSS3 (CSS Variables, Flexbox, Grid), Modern JavaScript (ES6+ Modules, DOM API)
- **Icons & Fonts:** Font Awesome 6.5.1
- **Localization:** Vanilla JS Dictionary-based i18n System
- **Architecture:** Static Web Application (GitHub Pages Compatible)
